# Address bar and right-click menu

You don't have to open the popup.

## From the address bar

1. Click the address bar (or press `⌘`/`Ctrl` + `L`).
2. Type `j`, then press **Space**. The bar shows "Issue Jump".
3. Type a key, a number or a few words and press **Enter**.

Everything the popup understands works here: `WEB-123`, `123`, `acme/web#45`, several keys at once. Your recent issues appear as suggestions while you type.

- `Enter` opens in the current tab.
- `Alt` + `Enter` (Windows, Linux) or `⌘` + `Enter` (Mac) opens in a new tab.

If the text isn't an issue, it opens a search in your main tracker.

## From selected text

1. Select an issue key or reference on any page, for example in a chat message or a document.
2. Right-click and choose **Jump to "…"**.

It opens in a new tab beside the one you are on. Selecting several keys opens them all.
