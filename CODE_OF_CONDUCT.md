# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful and assume good intent.
- Critique code and ideas, not people.
- No harassment, insults, or unwelcome personal attention of any kind.
- Respect people's time: reviews and replies come from volunteers.

This applies in issues, pull requests, discussions and anywhere else the project is represented.

## Reporting

If someone's behaviour is a problem, report it privately to the maintainer through the contact options on
[their GitHub profile](https://github.com/rejochandran). Reports are kept confidential. The maintainer may
remove comments, close threads or block accounts that break this code.
